Ajuda e privacidade

Escreva normalmente para conversar com o THIGAS. As respostas vêm da IA configurada no servidor.

/help ou /ajuda
Abre esta ajuda.
/clear ou /novo
Apaga a conversa salva neste navegador.
/theme green|amber|cyan|pink
Comando legado de tema.
/sound
Liga ou desliga os sons.
/cat
Mostra um gato ASCII.
/thigas pergunta
Envia uma pergunta à IA.

Você pode anexar texto ou código UTF-8 de até 256 KiB. Mensagem e anexo juntos podem ter até 60.000 caracteres. Imagens, PDF e ZIP ainda não são interpretados nesta versão.

Blocos de código podem ser copiados ou baixados. A interface não executa os códigos automaticamente.

Privacidade

Seu texto, anexos enviados e parte do histórico são encaminhados ao provedor de IA configurado no servidor para gerar a resposta. Não envie senhas, chaves de API ou dados sensíveis.

O histórico fica salvo apenas neste navegador. O PWA pode abrir a interface sem internet depois do primeiro carregamento, mas novas respostas exigem conexão.

Instalar THIGAS AI

O THIGAS pode ser instalado diretamente pelo navegador, sem APK.

Android: abra no Chrome e use o menu ⋮ → Instalar aplicativo ou Adicionar à tela inicial.

Computador: use o botão de instalação disponível na barra de endereço do Chrome ou Edge.

iPhone/iPad: abra no Safari e escolha Compartilhar → Adicionar à Tela de Início.

📎 Anexe texto ou código UTF-8 até 256 KiB. Mensagem e anexo juntos: até 60.000 caracteres. Imagens, PDF e ZIP não são interpretados nesta versão.

Blocos de código nas respostas podem ser copiados ou baixados. O site não executa códigos nem testes.

Privacidade e limites

Seu texto, anexos enviados e parte do histórico são encaminhados à Maritaca para gerar a resposta. Não envie senhas, chaves de API ou dados sensíveis. O histórico fica no armazenamento deste navegador; não é sincronizado com o Telegram.

O uso da API consome o saldo do responsável pelo servidor. A hospedagem gratuita pode precisar de tempo para despertar. Uma falha não gera uma tentativa automática.
